## Актуальность

Поиск B2B-партнёров и подготовка коммерческих предложений (КП) в большинстве компаний выполняются вручную: менеджер изучает потенциального партнёра и адаптирует типовой шаблон КП. Это долго, плохо масштабируется, а шаблонные КП не учитывают отрасль, масштаб и потребности конкретного партнёра. Большие языковые модели (LLM) позволяют генерировать связный персонализированный текст на основе данных о компании, а рекомендательные системы позволяют отбирать партнёров с наибольшей вероятностью отклика.

## Цель

Разработать веб-сервис и Telegram-бот, которые по описанию бизнеса заказчика подбирают и ранжируют B2B-партнёров и выдают топ-N контактов с персонализированными письмами-предложениями, сгенерированными LLM.

## Продукт

Веб-сервис и Telegram-бот на общем API:

1. Заказчик описывает свой бизнес (в веб-форме или в чате бота).
2. Система собирает базу потенциальных партнёров и конкурентов.
3. Компании ранжируются по релевантности бизнесу заказчика.
4. Для каждой компании из топ-N LLM пишет персонализированное письмо для рассылки.
5. Заказчик получает топ-N контактов с готовыми письмами.

## Задачи

1. Проанализировать предметную область, существующие рекомендательные системы и решения на базе LLM.
2. Реализовать сбор базы компаний (партнёров и конкурентов) по описанию бизнеса заказчика.
3. Разработать модель подбора и ранжирования потенциальных партнёров.
4. Разработать модуль генерации персонализированных писем-КП на базе LLM с RAG.
5. Реализовать веб-сервис и Telegram-бот на общем API.
6. Оценить качество рекомендаций и сгенерированных предложений.

## Объект и предмет исследования

- **Объект:** процесс поиска B2B-партнёров и подготовки коммерческих предложений в отделах продаж и развития бизнеса.
- **Предмет:** методы и алгоритмы генеративных рекомендательных систем и больших языковых моделей для подбора партнёров и персонализации КП.

## Архитектура

```
Описание бизнеса заказчика (веб-сервис / Telegram-бот)
      │
      ▼
Сбор базы партнёров и конкурентов (реестры, сайты компаний)
      │
      ▼
Ранжирование (векторный поиск по эмбеддингам + градиентный бустинг)
      │
      ▼
Генерация писем (LLM + RAG по данным о каждой компании)
      │
      ▼
Топ-N контактов с готовыми письмами для рассылки
```

## Данные (предполагаемые источники)

| Источник | Содержание | Использование |
|---|---|---|
| Открытые реестры компаний (ФНС, ЕГРЮЛ) | Отрасль (ОКВЭД), регион, размер, возраст | Признаки профиля компании |
| Сайты и описания компаний | Тексты о продуктах и услугах | Эмбеддинги, контекст для LLM (RAG) |
| История взаимодействий (обезличенная или синтетическая) | Сделки, отклики, статусы КП | Обучение и оценка ранжирования |
| Корпус коммерческих предложений | Структура и формулировки КП | Промпты, few-shot примеры, оценка генерации |

## Стек технологий

- **Данные:** Python, pandas, PostgreSQL, pgvector
- **Рекомендации:** PyTorch, sentence-transformers, CatBoost
- **LLM и RAG:** open-source LLM (Qwen, Llama) через vLLM или GigaChat API, LangChain
- **Бэкенд:** FastAPI, Docker, Docker Compose
- **Интерфейсы:** веб-сервис (React или Streamlit), Telegram-бот (aiogram)
- **Сопровождение:** Git, «Сфера Код», MLflow
